关于本归档

这是一个纯前端的 SPA（单页应用）历史归档站，用于归档「海垦日报」每日自动生成的 HTML 报告。

架构

  • 外壳 index.html + app.js + styles.css：列表/路由/渲染
  • 数据 data/manifest.json：期次清单（日期/标题/标签/文件路径）
  • 内容 issues/YYYY-MM-DD.html：每期日报独立 HTML，iframe 载入

新增一期

  1. 把日报 HTML 丢进 issues/（命名 YYYY-MM-DD.html）
  2. 在 data/manifest.json 的 issues 数组顶部加一条
  3. 刷新页面即可

本地运行

cd haiken-archive
python -m http.server 8080
# 浏览器打开 http://localhost:8080

直接双击 index.html 也能看（但 fetch manifest 需要 http 协议，建议用上面的本地服务器）。
